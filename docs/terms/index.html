Draft provisions

  1. The integration is intended as a personal, non-commercial, single-user tool for the owner alone. Other people are outside that intended use. The integration is not enabled, so these pages offer nothing to operate.
  2. The project is separate from Oura. If the Oura API were used later, Oura's own terms and Oura's API agreement would govern use of that API. This page does not accept that agreement, does not submit an Oura application, and does not authorize access to health data.
  3. The intended server is community open-source software, the .NET project gjlumsden/oura-mcp. This draft describes that software as provided as is. The draft offers no warranty and does not say the software is reliable, accurate, or fit for a particular purpose. The intended integration is not a medical device and would not give medical advice. This draft claims no medical, security, or compliance certification.
  4. The owner may change or stop the integration, and may revoke OAuth access. Those sentences describe the owner's intended freedom of action. This website does not operate a start, stop, or revoke control.
  5. The operator contact method is unconfirmed. No address is stated, because none has been confirmed.

What this draft leaves open

Exact OAuth scopes, data and model providers, other recipients, token and data storage, retention and deletion, and an operator contact are unconfirmed. The privacy draft lists those same open items. This terms draft adds no rule that would close them, and it adds no commitment about sharing, selling, advertising, retention, or deletion.

The intended host, if the integration were later enabled, is a shared hosted computer used by the owner's AI assistants, separate from the owner's physical machine. Retrieved Oura information may be sent through HealthBot to the AI service providers that process the assistant's conversation. The provider names are unconfirmed.

This website

These pages are static public text for the period before activation. The HTML includes no form and no sign-in. The pages do not collect health information, and they do not connect to Oura.
