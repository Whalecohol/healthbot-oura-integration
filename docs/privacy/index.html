Privacy draft

Not enabled. Provisional draft, dated 8 November 2026 (2026-11-08). The owner has not adopted this text.

This is not an adopted privacy policy. The date is a drafting date, before activation. The integration these sentences describe is not running.

This draft talks about one person, the owner, and a personal Oura connection that has not been turned on. HealthBot Personal Oura Integration is not affiliated with or endorsed by Oura Health Oy.

How to read this page

The page explains an intended design and lists what is still open. It does not describe a live collection practice, because the integration is not enabled. The owner has not adopted this text. Putting the draft on a public website does not adopt it.

Where this page is silent, the silence is intentional. Unconfirmed items stay unconfirmed until the owner confirms them elsewhere. This page does not supply stand-in answers.

Who it would cover

The intended scope is the owner, using the integration for themselves. The intended use is personal, single-user, and non-commercial. The draft does not describe a service offered to other people, and there is no service to join while the integration remains disabled.

Information the design would handle

If the owner later enables the integration, the intended design would handle two kinds of material:

  • Oura data the owner authorizes through Oura's official OAuth. The exact scopes are unconfirmed. This draft does not choose them. Sleep, activity, readiness, and heart rate are examples of categories Oura can make available. They are not a confirmed scope list.
  • OAuth access tokens and refresh tokens for that connection.

This website does not collect that material. The pages are static text. They contain no Oura data and no tokens.

Intended path

  1. Oura's API would send authorized data to an MCP server on a shared hosted computer used by the owner's AI assistants. That computer is separate from the owner's physical machine.
  2. When HealthBot calls the server's tools, the returned Oura information becomes part of the assistant's conversation.
  3. Retrieved information may be sent through HealthBot to the AI service providers that process the conversation. Which providers, and what their own terms say about retention or use, is unconfirmed.

The MCP server in that design is the community open-source .NET project gjlumsden/oura-mcp. This privacy draft does not operate that server.

Sharing, selling, and advertising

The intended path above already includes a possible disclosure to HealthBot's AI service providers. Any further recipient is unconfirmed.

This draft sets no rule against sharing, selling, or advertising, and it describes no control that would prevent them. A reader should not treat any sentence here as a promise about those uses.

Storage, retention, and deletion

Storage is unconfirmed. The draft does not say whether the server would store tokens or Oura data on the hosted computer, and it does not name a storage location.

Retention is unconfirmed. The draft does not say how long tokens, Oura data, or conversation logs would be kept.

Deletion is unconfirmed. The draft does not describe how the owner would delete copies on the hosted computer, in HealthBot, or in a provider's systems.

Because those points are unconfirmed, this page states no retention period and no deletion method.

Access at Oura

The owner can revoke an integration's access in their Oura account settings. That control belongs to the owner's Oura account. What happens to any later copy, including how local deletion would work, is unconfirmed. This page does not walk through a revocation procedure, because the integration is not enabled and the deletion path is unconfirmed.

This website

The pages are static files. The HTML includes no form, no account, and no analytics script. The pages do not ask for health information.

If GitHub Pages publishes the files, GitHub hosts them. This draft does not describe GitHub's own systems, logs, or retention.

Contact

The operator contact method is unconfirmed. No email address or other contact channel is stated, because none has been confirmed.
